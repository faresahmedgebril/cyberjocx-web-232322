# مصادر مرجعية للمسارات التعليمية

يستخدم CyberJocx هذه الروابط كمراجع خارجية للوحدات التعليمية؛ وهي ليست محتوى مستضافًا أو مملوكًا للمنصة. تُفتح الروابط في نافذة جديدة، ويجب احترام شروط كل ناشر.

| المسار | المصدر | الاستخدام داخل roadmap |
| --- | --- | --- |
| API Security | [OWASP API Security Project](https://owasp.org/www-project-api-security/) | مرجع Top 10 ومفاهيم الضوابط الأمنية، ويتضمن رابط حديثًا مرئيًا من OWASP Global. |
| API Security | [APIsec University Fundamentals](https://www.apisecuniversity.com/courses/api-security-fundamentals) | مرجع هيكلة الدروس: مقدمة، هجمات واقعية، OWASP Top 10، الحوكمة والاختبار والمراقبة. |
| Network Defense | [Infosec Network Security Fundamentals](https://www.infosecinstitute.com/skills/learning-paths/network-security-fundamentals/) | مرجع مخرجات الأساسيات: الشبكات، اللاسلكي، الجدار الناري وIDS/IPS وVPN ونقاط النهاية. |
| DevOps / Network | [Google Cloud Networking & Security](https://cloud.google.com/learn/training/networking-security) | مرجع مهارات الشبكات السحابية وIAM والمراقبة وحماية الأحمال. |

## ملاحظة المحتوى المرئي

الوحدات في قاعدة البيانات تحتوي حقلاً للرابط المرئي. يجب استبدال روابط القنوات المرجعية بروابط فيديوهات المنصة أو فيديوهات مرخّصة يختارها المالك عند تجهيز المحتوى الكامل.
