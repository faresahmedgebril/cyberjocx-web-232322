# CyberJocx — مرجع الأسعار الموحد
**الإصدار:** 25 أكتوبر 2026  
**العملة:** الجنيه المصري (EGP)  
**الغرض:** مصدر مرجعي موحد للأسعار المستخدمة في خطة العمل والنموذج المالي وBMC.

## الأسعار الحالية المعتمدة للتخطيط

| المنتج | السعر | وحدة التسعير | ملاحظات |
|---|---:|---|---|
| الاشتراك الأساسي | 600 جنيه | لكل شهر اشتراك | سعر تخطيطي يحتاج إلى اختبار بيع فعلي |
| الاشتراك الأعلى | 1,000 جنيه | لكل شهر اشتراك | يجب توضيح الفروق الفعلية في المزايا والدعم وحدود الاستخدام قبل البيع |
| البرنامج الخاص / Special Program | 3,500 جنيه | لكل مشارك في البرنامج الواحد | ليس اشتراكًا شهريًا؛ لا يبدأ البيع قبل اعتماد السعة والتكلفة المباشرة |
| CTF خلال أول 3 أشهر من الإطلاق | مجانًا | لكل مشارك | لا يُسجّل إيراد دخول خلال فترة الإعفاء |
| CTF بعد أول 3 أشهر | 300 جنيه | لكل مشارك مدفوع لكل فعالية | الإيراد = عدد المشاركين الذين دفعوا فعليًا × 300 جنيه؛ لا تُحسب التسجيلات المجانية كمبيعات |

## قواعد احتساب الإيراد

1. لا يوجد مزيج فعلي معروف بين الباقة الأساسية والأعلى قبل وجود بيانات دفع. لذلك لا يُعتمد ARPU ثابت قدره 720 جنيهًا أو نسبة 70%/30% بوصفها حقيقة.
2. نطاق ARPU النظري للاشتراكات بين 600 و1,000 جنيه شهريًا. عند إعداد سيناريو محافظ، يستخدم النموذج 600 جنيه لكل شهر اشتراك حتى تتوافر بيانات تحصيل حسب الباقة.
3. دخل البرامج الخاصة وCTF مستقل عن دخل الاشتراكات، ولا يُضاف أي دخل CTF إلى أول 3 أشهر.
4. جميع الأسعار هنا أسعار تخطيطية وليست دليلًا على بيع فعلي أو إيراد متحقق. يلزم اختبار السعر وتوثيق التحصيل والاستردادات والإلغاءات.
5. لا تشمل الأسعار وحدها حكمًا بشأن الضرائب أو ضريبة القيمة المضافة؛ يلزم حسم المعاملة مع محاسب مصري قبل الفوترة.

## أمثلة حسابية مباشرة

- 20 مقعدًا في برنامج خاص: 20 × 3,500 = **70,000 جنيه إيراد إجمالي** إذا بيعت كل المقاعد.
- 200 مشارك مدفوع في فعالية CTF بعد انتهاء الفترة المجانية: 200 × 300 = **60,000 جنيه إيراد إجمالي** قبل خصم تكلفة الفعالية.
- لا يُفترض أن الإيراد الإجمالي ربح؛ يجب طرح المدرب، والجوائز، والتشغيل، والتسويق، ورسوم الدفع، والضرائب وأي مصروفات مباشرة أخرى.
